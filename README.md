# SACCO Cloud ERP - Live Production System
Live Demo: https://sacco-system-three.vercel.app
Architecture: AWS EC2 (Ubuntu 22.04) + RDS MySQL + Node.js/Express + Power BI + MPESA Daraja STK Push

## What it does
- Member registration, savings, loans - large database-driven ERP
- MPESA STK Push Lipa Na MPESA Online + Callback URL handling -> mpesa_callbacks table
- Real-time Power BI dashboard pulling from RDS MySQL via Direct Query
- KPIs: Ksh 1.2M MPESA tracked, 342 members, 92.4% success rate, Ksh 4.2M savings

## Tech Stack
Node.js, Express, AWS EC2, AWS RDS MySQL, Power BI, DAX, MPESA Daraja API, Git, Linux
